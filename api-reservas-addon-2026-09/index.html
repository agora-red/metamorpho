Qué datos y acciones incluye · Alcance propuesto

Agenda y horarios

Reservas actuales e históricas, disponibilidad, servicio, profesional, sucursal y estado. Crear, reprogramar y cancelar respetando las reglas del negocio.

Clientes

Buscar, crear y actualizar clientes. Nombre, contacto autorizado e historial de visitas. Los permisos de contacto se eligen por separado.

Ventas y cobros

Consultar ventas, importes cobrados, señas, devoluciones registradas y saldos pendientes. Filtrar por fecha y sucursal; distinguir lo vendido de lo cobrado.

Cambios automáticos

Avisar cuando se crea, confirma, mueve o cancela una reserva; cuando vence, se completa o registra una ausencia; cuando cambia un cliente o se registra un pago o devolución.

En ChatGPT, empezamos con consultas. Las automatizaciones y la API sumarían cambios de reservas y clientes. El alcance de cada conector se valida antes de publicarlo.

Productos y stock, comisiones, planes mensuales y packs quedan para una ampliación. Son capacidades del producto; su conexión externa no forma parte de esta primera propuesta.

Una base común, cuatro conectores
API propuesta /public/v1, con OAuth por negocio y permisos separados para catálogo, disponibilidad, reservas, clientes, contactos y finanzas. El plugin de ChatGPT usa un servidor MCP propio para profesionales. La API directa admite credenciales revocables para sistemas propios. El MCP administrativo no se expone.


Cada operación verifica identidad, negocio, sucursales, permisos, adicional activo y cupo. Los avisos también se detienen al desactivar el adicional. Una clave válida no permite saltar el control comercial. Los tokens se guardan en el gestor de credenciales del proveedor, nunca en el chat ni en una web pública.


Reglas que deben mantenerse
  • Crear o mover vuelve a validar disponibilidad; reintentar el mismo pedido no duplica la reserva. Si falla una reprogramación, se conserva el turno anterior.
  • Ágora calcula precios y señas. Una reserva con seña queda pendiente hasta verificar el pago; se entrega el enlace de Ágora y el vencimiento. Cancelar no ejecuta un reembolso.
  • Fechas con zona horaria; importes enteros en centavos y moneda. Los listados tienen paginación e historial. Los contactos requieren permiso adicional; las fichas sensibles quedan fuera.
  • Avisos firmados con ID y versión, reintentos, historial de fallos y recuperación de cambios perdidos. Los conectores actualizan por ID, toleran duplicados y evitan bucles.
  • Los conectores registran sus avisos al activar una automatización. El profesional elige un evento de Ágora; no copia una dirección de webhook.


Antes de cobrar
Probar conexión y revocación; aislamiento entre negocios; adicional vencido; límites; reservas simultáneas; señas y vencimientos; cambios sin pérdida del turno; sincronización sin duplicados; recuperación tras una interrupción. Validar cada recorrido en su plataforma real.

Detalle técnico · Cómo se cuentan los usos
Cada página leída cuenta como consulta; cada cambio exitoso de reserva o cliente, como acción. Reintentos con la misma clave no duplican acciones. Los permisos y cupos se comparten por negocio, no se multiplican por sucursal o herramienta.
Reinicio a medianoche en la zona horaria de facturación del negocio. Se elimina el tope anterior de dos conexiones; no se promete uso ilimitado. Volumen de avisos, conexiones simultáneas y política de reintentos se dimensionan en el piloto antes de fijar la oferta comercial.

El adicional se controla en Ágora
El conector puede ser público; acceder al negocio requiere el adicional. En ChatGPT se conecta una cuenta paga existente: no se vende ni promociona la suscripción dentro del plugin y no se cobra un recargo exclusivo por ese canal. Reglas de OpenAI.
Zapier no permite ejecutar transacciones financieras. Se proponen consultas y avisos sobre cobros, con el pago realizado en Ágora. Las acciones finales y los flujos con seña requieren validación por proveedor. No hay fechas de aprobación garantizadas.
Ágora mantiene versiones y soporte de sus conectores; el profesional configura sus automatizaciones y cuentas. Conectar servicios no autoriza a acceder a otros negocios. Fuentes oficiales revisadas el 2 de octubre de 2026.
