Contrato propuesto, no API operativa. Una API es el acceso que permite que otro programa trabaje con Ágora. El alcance inicial es catálogo de servicios, profesionales, sucursales, disponibilidad y reservas de servicios. Las tres vías usan los mismos permisos y cupos. La aplicación, las conexiones y el cobro del adicional requieren desarrollo y pruebas.


Acceso. Claves revocables por conexión para sistemas propios; OAuth 2.1 y un servidor MCP de alcance limitado para asistentes. El servidor verifica negocio, permiso y sucursal en cada operación. Nada de acceso al MCP administrativo. Sin teléfonos, emails ni fichas en las consultas del asistente por defecto. Las claves nunca van en el navegador público ni se pegan en el chat. Autenticación de OpenAI.


Reservas. Consultar un horario no lo bloquea. Crear o mover vuelve a validar disponibilidad y políticas; los pedidos simultáneos no pueden duplicar el turno. Repetir el mismo pedido no crea otra reserva ni consume otra acción. Si falla un cambio, se conserva el turno anterior. Cancelar aplica la política acordada y no equivale a reembolsar.


Señas y datos. Con seña, se entrega el enlace de pago y el vencimiento; la reserva queda pendiente hasta verificar el pago. Sin pago, vence y libera el horario. Un pago tardío requiere conciliación. Ágora calcula el precio; la integración no marca pagos como cobrados. El contrato inicial requiere nombre y email. Preguntas, adicionales y visitas con varios servicios deben conservar sus reglas o rechazarse explícitamente: nunca ignorarlas.


Avisos. Altas, confirmaciones, cambios, cancelaciones y vencimientos de reservas de todos los canales dentro del alcance autorizado. Cada aviso necesita identificador, versión, firma, reintentos y registro de fallos. El receptor debe tolerar duplicados y desorden. Para Zapier hay que resolver suscripciones o consultas periódicas; una API genérica no equivale a un conector publicado. Documentación de Zapier.


Cupos. Cada página leída cuenta como consulta; cada creación, cambio o cancelación exitosa cuenta como acción. Los errores de validación no consumen acciones, aunque se limita el abuso. El día se renueva a medianoche en la zona horaria de facturación del negocio. Varias sucursales del mismo negocio comparten cupos; negocios independientes requieren autorizaciones separadas. Precio para grupos, volumen de avisos y reintentos: pendientes antes del piloto.


Modelo comercial. La propuesta cobra en Ágora por un servicio general de integraciones con valor propio. OpenAI permite acceder con cuentas pagas existentes, pero prohíbe vender suscripciones dentro del plugin y cobrar un recargo específico por usar ChatGPT. Este diseño es una propuesta a validar con OpenAI; no implica aprobación ni disponibilidad en su directorio. Reglas de OpenAI.


Antes de cobrar. Probar con el sistema del piloto: conexión y revocación, aislamiento entre negocios, cupos, pedidos simultáneos, reintentos, pagos y vencimientos, cambios sin pérdida de turno, entrega y recuperación de avisos. El piloto debe resolver una tarea real de principio a fin; ni una maqueta ni pruebas del simulador certifican estas integraciones.


Fuentes externas verificadas el 1 de octubre de 2026. Los valores comerciales y el alcance de este documento son propuestas para decidir.

03
Qué no incluye.


  • La suscripción a ChatGPT, Zapier, Make o n8n.
  • El trabajo de una persona que configure o programe la conexión.
  • Acceso a caja, fichas privadas, cobros o devoluciones.
  • Cambiar precios o servicios; gestionar cursos, turnos recurrentes o planes mensuales.
El alcance inicial se concentra en turnos de servicios. Cada herramienta necesita una conexión desarrollada y probada antes de ofrecerla.

¿Qué pagarías a Ágora? El permiso para que hasta dos herramientas usen tu agenda, con los límites de arriba.
  1. Elegís una tarea. Por ejemplo, llevar los turnos a tu planilla.
  2. Se prepara y prueba. Acordamos quién configura, cuánto cuesta ese trabajo y qué datos autorizás.

Primero, una prueba con un negocio. Todavía hay que desarrollar las conexiones y validar el precio.
